ความเป็นส่วนตัวและการใช้ข้อมูล

ปรับปรุง 30 ตุลาคม 2569

ข้อมูลที่เครื่องมือเข้าถึง

เครื่องมือใช้ Google Drive API ด้วยสิทธิ์ drive.file สำหรับไฟล์ที่เครื่องมือสร้างหรือผู้ใช้เลือกให้เข้าถึง และตรวจอีเมลบัญชีที่เชื่อมต่อเพื่อป้องกันการส่งสำรองผิดบัญชี สิทธิ์นี้รองรับการอ่าน สร้าง แก้ไข และลบไฟล์ในขอบเขตดังกล่าว แต่ยังไม่ได้เปิดงานลบสำรองอัตโนมัติ

วัตถุประสงค์และสถานะปัจจุบัน

ใช้เพื่อจัดเก็บสำรองและตรวจสอบการกู้คืน ปัจจุบันทดสอบเพียงไฟล์จำลองที่เข้ารหัส ข้อมูลยืนยันตัวตนเก็บในโฟลเดอร์ที่จำกัดสิทธิ์บน Mac ของเจ้าของ ยังไม่ได้เปิดการส่งข้อมูลธุรกิจหรือส่งข้อมูลยืนยันตัวตนไปเครื่องรันบนคลาวด์

การเตรียมใช้งานจริง

แนวทางที่อยู่ระหว่างเตรียมคือให้เครื่องรันส่วนตัวบน GitHub Actions ประมวลผลสำรอง REPORT ชั่วคราว เข้ารหัส แล้วจัดเก็บใน Drive ของเจ้าของ สำรองจริงอาจมีประวัติยอดขายและข้อมูลติดต่อของลูกค้า ต้องตรวจสิทธิ์และทดสอบกู้คืนก่อนเปิดใช้งาน จะปรับข้อมูลหน้านี้ให้ตรงกับการทำงานจริงเมื่อเปิดใช้

การเก็บรักษาและการควบคุม

ไม่มีการลบสำรองเดิมโดยอัตโนมัติ การยกเลิกการเชื่อมต่อ Google จะหยุดการเข้าถึงครั้งต่อไป แต่ไม่ลบไฟล์ที่เก็บไว้แล้ว การขอเข้าถึงหรือลบสำเนาให้ติดต่อผู้ดูแลเพื่อพิจารณาร่วมกับข้อกำหนดการเก็บข้อมูลของกิจการ
